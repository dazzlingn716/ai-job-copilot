# 实验 3：Docker 操作记录

## 1. Docker 环境验证

- Docker Desktop 与 Ubuntu WSL 2 集成成功。
- `docker run hello-world` 输出 `Hello from Docker!`。
- Python 临时容器输出 `Hello from Python container`。

## 2. 项目镜像与容器

项目通过 `Dockerfile` 构建为 `ai-job-copilot:v1`，并映射端口 `8000:8000`。浏览器访问 `http://localhost:8000` 可完成岗位匹配分析。

常用验证命令：

```bash
docker build -t ai-job-copilot:v1 .
docker run -d --name ai-job-copilot -p 8000:8000 ai-job-copilot:v1
docker ps
docker logs ai-job-copilot
docker exec -it ai-job-copilot sh
```

## 3. 数据卷

创建 `ai-job-data` 数据卷，先由一个临时容器写入文件，再由另一个临时容器读取，成功输出 `AI Job Copilot volume test`，证明容器删除后数据仍然保留。

```bash
docker volume create ai-job-data
docker run --rm -v ai-job-data:/data python:3.11-slim sh -c "echo 'AI Job Copilot volume test' > /data/proof.txt"
docker run --rm -v ai-job-data:/data python:3.11-slim cat /data/proof.txt
```

## 4. 自定义网络

创建 `ai-job-network`，将项目容器加入网络，再使用临时 Python 容器通过容器名称访问项目，返回状态码 `200`。

```bash
docker network create ai-job-network
docker network connect ai-job-network ai-job-copilot
docker run --rm --network ai-job-network python:3.11-slim python -c "import urllib.request; print(urllib.request.urlopen('http://ai-job-copilot:8000').status)"
```

## 5. Docker Compose

`compose.yaml` 统一配置项目镜像、端口、数据卷和网络。Compose 容器通过 `http://localhost:8001` 访问成功。

```bash
docker compose up -d
docker compose ps
docker compose down
```

## 6. Nginx 目录挂载

将主机目录 `nginx-demo` 只读挂载到 Nginx 默认站点目录，映射端口 `8080:80`。访问 `http://localhost:8080` 显示“Nginx 目录挂载成功”。

```bash
docker run -d --name nginx-demo -p 8080:80 -v "$(pwd)/nginx-demo:/usr/share/nginx/html:ro" nginx:alpine
```

## 7. MongoDB 与 Mongo Express

MongoDB 和 Mongo Express 位于同一个 `ai-job-network`。MongoDB 命令返回 `ping=1`，Mongo Express 管理页面通过 `http://localhost:8082` 成功访问，证明两个容器可以通过服务名称通信。MongoDB 数据保存在 `mongo-data` 数据卷中。
